Шаблоны документов

Данные из 1С: скопируйте диапазон (как в Excel) → вставьте в блок «Вставить из 1С / Excel» или в первую ячейку таблицы (Ctrl+V). Столбцы через Tab, строки с новой строки. Подписи и колонтитулы — как в исходных шаблонах.

Общие данные

Данные документа

Комплект: печать и Excel

Состав комплекта (Excel и база для печати). Перед печатью откроется окно выбора. Порядок по умолчанию: Распоряжение → Комплект → Материалы → Ф3 → Ф2 → Ф1 → остальное.

Действия

Печать комплекта — выбор форм перед печатью. Excel: те же данные, что на печать + поля A4 и колонтитулы «… Страница &P из &N» на каждом листе (как в превью). Откройте файл → Разметка страницы / колонтитулы.

Локальные сохранения

Черновик пишется в браузер автоматически. Именованные снимки — для быстрой загрузки вставленных данных.

Превью

Печать комплекта

Отметьте формы и задайте порядок (↑↓). По умолчанию: Распоряжение → Комплект → Материалы → Ф3 → Ф2 → Ф1 → остальное.
