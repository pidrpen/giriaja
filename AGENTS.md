## Главный продукт последней работы: `document-templates.html`

Один self-contained HTML (~120 KB), без сборки. Открывается в браузере.

### Бизнес-задача
Заполнить формы из Excel/Word-шаблонов завода данными из **1С** (вставка как в Excel: Tab/строки), печатать A4 и выгружать **тот же вид** в Excel (SpreadsheetML `.xls`).

### Формы
- **f1, f2, f3** — сводные ведомости трудоёмкости  
- **mat** — материальная ведомость (иерархия «красная строка» / отступы)  
- **stat** — статистика выгрузки + контрольные суммы  
- **kit** — сопроводительный «Комплект документов»  
- **rasp** — распоряжение о запуске спецификаций  
- **cmp** — сравнение спецификаций  

### Ключевые решения (не ломать без причины)

1. **Вставка из 1С**  
   - Блок «Вставить из 1С / Excel» + Ctrl+V в ячейки  
   - Tab / `;` / HTML-table; числа `1 234,56`; **не trim слева** (нужны пробелы иерархии)  
   - Шапка и строки «Итого» при вставке отбрасываются  

2. **«Итого»**  
   - Сразу **под шапкой** таблицы, суммы по всем данным  
   - Не внизу таблицы  

3. **Материалы — заливка**  
   - Без отступа (красная строка) → `row-parent` / Excel `parent` (жёлтый)  
   - С 2+ пробелами/табом → белый `row-child` / `data`  

4. **Подписи Excel-форм**  
   - Сразу **под таблицей** (~10 mm), не прижаты к низу листа  
   - Word (kit/rasp): как в docx, должность слева / ФИО справа  

5. **Печать комплекта**  
   - Перед печатью **модалка**: галочки + ↑↓  
   - Порядок по умолчанию:  
     **`rasp → kit → mat → f3 → f2 → f1 → stat → cmp`**  
   - Константа: `DEFAULT_PACK`  

6. **Комплект — автолистование**  
   - `countDocPages` / `recalcKitPages` / `naListah` / `listovForm`  
   - «на 1 листе» / «на 2 листах» / «на 5 листах» / «на 21 листе»  
   - Ручной ввод числа листов **убран** (только пересчёт)  

7. **Excel-выгрузка = печать**  
   - `buildPrintMatrix(id)` → `exportMatrixF*` / Kit / Rasp  
   - `sheetFromMatrix` + **pageSetup**: A4, поля, колонтитул  
     `… Страница &P из &N` (как HTML footer)  
   - **kit/rasp**: длинный текст **по строкам** (`wrapLines`), не монолит в одной ячейке  
   - Высоты строк фиксированные (`ss:Height`), ширины колонок заданы  

8. **Образец данных**  
   - Кнопка «Образец данных» → `fillSampleData()` (изделие УМ-450.12.001 и т.д.)  

9. **Сохранение**  
   - `localStorage` ключ `doc_templates_fill_v1` (включая `state.pack`)

## Как тестировать после правок

1. Открыть `document-templates.html` в Chrome/Edge  
2. «Образец данных»  
3. Вкладки форм, превью A4  
4. Печать комплекта → модалка порядка  
5. Excel: текущий / комплект → открыть в Excel:  
   - Итого под шапкой  
   - Колонтитулы (Разметка страницы)  
   - Распоряжение/Комплект без огромной ячейки  
6. Вставка: скопировать TSV из Excel/1С в блок вставки

## Чего избегать

- Не тащить React/сборка — один HTML осознанно  
- Не `trim()` названий номенклатуры слева  
- Не возвращать «Итого» вниз таблицы  
- Не `margin-top: auto` у подписей Excel-форм (прижимает к низу листа)  
- Не один merge-cell на весь текст kit/rasp  
- Не менять `DEFAULT_PACK` без согласования с пользователем
