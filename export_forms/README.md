# Модули выгрузки форм в Excel

Субагенты сгенерировали билдеры матриц листов:

| Файл | Формы |
|------|--------|
| `f1_f2.js` | Форма 1, Форма 2 |
| `f3_mat.js` | Форма 3, Материалы |
| `stat_cmp.js` | Статистика, Сравнение |
| `kit_rasp.js` | Комплект, Распоряжение (построчный бланк, без монолита) |

Логика **вшита** в `заполнение_документов.html` (`exportMatrix*` + `buildPrintMatrix` + `sheetFromMatrix`).  
Эти файлы — исходные эталоны для правок по отдельным формам.
