# Следующая сессия (из приложения)

1. Открой репозиторий **pidrpen/giriaja** в приложении (Grok / Cursor / VS Code).
2. **Прочитай `AGENTS.md` целиком** — там весь контекст по шаблонам документов и хабу.
3. Рабочий файл шаблонов: **`document-templates.html`**.
4. **Расчётник резки:** **`cutting-calculator.html`** — нормы из приложения 2 (лазер/плазма/газ).
5. Ссылка с главной: **`index.html`** → карточки «Шаблоны документов» / «Расчётник резки».

Не начинай с нуля: логика печати, Excel, вставки из 1С, порядок комплекта и расчётник уже реализованы.
